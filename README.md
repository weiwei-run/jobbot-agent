# JobBot Agent — 本地 AI 求职助手

一个下载即用、完全跑在你自己电脑上的 AI 求职助手。**它不帮你投递，而是帮你把"找到最值得投的岗位"这件事做到极致**：

- 上传简历、写一句求职意向，JobBot 根据你的**学历、技能、证书、目标城市、目标岗位**生成搜索关键词，在 **BOSS直聘 / 前程无忧(51job) / 实习僧** 三大平台搜索；
- AI 把每个岗位和你的简历、意向逐一比对，按**硬技能、项目实习、学历专业、证书、城市方向**五个维度打分（0~100 分），给出档位、命中证据与缺口，只把**最匹配的岗位**推荐给你（每页 10 条，支持按平台筛选）；
- 投递由你在岗位详情页**手动完成**：JobBot 提供详情链接，点开后到平台网页自己投递，投完点「加入记录」在本地看板跟进（已投递 → 已回复 → 约面试 → Offer/拒绝）。

> 数据全部留在本地：简历、API Key、投递记录都不上传，只有调用 AI 和搜索岗位时需要联网。

## 它能做什么

| 能力 | 说明 |
|------|------|
| 三平台搜索 | 51job（HTTP API + WAF 自动降级）、BOSS直聘 / 实习僧（Camofox 浏览器） |
| AI 评分匹配 | 根据简历+意向对每个岗位 0~100 分结构化评分（硬技能/项目/学历专业/证书/城市），带档位、命中证据与缺口 |
| 只推荐最匹配的 | 按总分排序每页展示 10 条，支持按平台筛选；50 分以下（观望档）不展示 |
| 岗位详情链接 | 每条推荐附详情链接，点击在浏览器打开岗位页面，**由你手动完成投递**（JobBot 不自动投递） |
| 简历解析 | 上传 TXT / Word / PDF，自动提取姓名、学历、专业、技能、证书填到意向里 |
| 投递记录看板 | 本地跟进：总览统计、状态流转（已投递→已回复→约面试→Offer/拒绝）、筛选、CSV 导出 |
| 诈骗检测 | 关键词/薪资虚高识别，可疑岗位打标提示 |
| 登录门禁 | 平台未登录/验证码时明确提示，绝不自动登录、绝不绕过 |

## 快速开始（三步）

### 1. 环境要求

- Windows / macOS / Linux
- Python 3.10+（https://python.org）
- Node.js 16+（仅 BOSS/实习僧搜索需要，用于 Camofox 浏览器）

### 2. 启动

```bash
python start.py
```

浏览器自动打开 `http://localhost:9379`。

### 3. 在页面里完成三件事

1. **配置 AI**：填写 LLM Base URL + API Key（DeepSeek / Kimi / 通义 / OpenAI 等任何 OpenAI 兼容接口），点「测试连接」。
2. **上传简历 / 填写意向**：上传简历（或直接写"大专，电气自动化，南京，PLC调试实习"），确认解析结果与目标城市，点「保存意向」。
3. **搜索与投递**：点「开始搜索」→ 查看 AI 评分结果（总分/档位/分项/证据）→ 点「打开详情投递」在浏览器打开岗位页面，**手动完成投递**；投递后点「加入记录」在本地看板跟进。

> 51job 搜索无需登录；BOSS直聘 / 实习僧 搜索需要安装 Camofox 浏览器并登录一次（页面「检测环境」会引导）。投递前请确认各平台简历已完善。

**登录门禁**：遇到平台未登录时，JobBot **不会自动登录、不填验证码、不绕过**。它会：把浏览器停在登录页 → 在 Dashboard 显示「🔐 需要手动登录」提示 → 等你手动登录完成后点「已登录，继续」→ 再继续搜索。未确认登录前不会执行任何搜索操作。

## 目录结构

```
jobbot-agent/
├─ start.py              # 一键启动（端口冲突自动检测）
├─ dashboard.py          # 本地看板（单文件，纯 stdlib）
├─ engine.py             # 核心引擎：关键词/搜索/评分/记录/状态
├─ platforms.py          # 三平台搜索（含 WAF/登录墙处理）
├─ browser.py            # Camofox 浏览器客户端
├─ llm.py                # OpenAI 兼容 LLM 客户端
├─ scripts/              # 自测脚本与 OCR 图片识别
├─ docs/                 # 使用文档（用户手册 / Agent 指南）
├─ config/
│  ├─ platforms.yml      # 平台开关与过滤规则（标题/薪资/学历/信任检测）
│  ├─ llm.json           # LLM 配置（本地，不入库）
│  └─ user_profile.json  # 求职意向（本地，不入库）
├─ data/                 # 投递记录与看板数据（本地）
└─ references/           # 平台对接参考资料
```

## 配置说明

- `config/platforms.yml`：每个平台的 `enabled` 开关、`title_filter.negative` 排除词、`salary_filter` 薪资范围、`education_allow` 学历白名单、`trust_filter` 信任检测关键词。排除词按你的求职方向调整（例如找技术岗时不要放 Java/Python）。
- `config/llm.json`：可在 Dashboard 填写，也可直接编辑；支持任意 OpenAI 兼容接口。

## 已知边界

- JobBot **不自动投递**：当前版本只提供岗位详情链接，投递动作由你在平台网页手动完成。
- BOSS直聘 / 实习僧 的页面结构可能随平台改版变化，搜索失败会给出明确提示，请按提示人工处理。
- 频繁操作可能触发平台风控（IP 封禁/验证码），遇到时放慢节奏或更换网络。
