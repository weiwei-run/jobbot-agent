# JobBot Agent 使用手册（普通用户版）

> 给第一次接触 JobBot 的求职者。全程不需要编程基础，照着做就行。

## 一、JobBot 是干什么的

JobBot 是一个跑在你自己电脑上的 AI 求职助手：

1. 你上传一份简历、写一句求职意向（城市、岗位、技能）；
2. JobBot 自动去 **BOSS直聘 / 前程无忧(51job) / 实习僧** 三大平台搜索岗位；
3. AI 按你的简历和意向给每个岗位打 0~100 分，只把最匹配的 10 个推荐给你，并说明**为什么推荐**（命中了你的哪些技能、还差什么）；
4. 你点岗位链接去网页上自己投递，投完点「加入记录」，之后在本地看板跟进（已投递 → 已回复 → 约面试 → Offer/拒绝）。

你的简历、API Key、投递记录**全部只存在你自己电脑上**。

## 二、需要准备什么

| 项目 | 说明 | 必需 |
|------|------|------|
| 一台电脑 | Windows / macOS / Linux 都行 | 必需 |
| Python 3.10+ | 到 https://python.org 下载安装 | 必需 |
| 一个 LLM API Key | 见下方「第三步：配置 AI」，推荐 DeepSeek（便宜够用） | 必需 |
| Node.js 16+ | 到 https://nodejs.org 下载安装；**只有用 BOSS直聘/实习僧搜索时才需要** | 可选 |

> 只用 51job 搜索的话，可以不装 Node.js。

## 三、怎么获取 JobBot

项目在 GitHub 和 Gitee 上各有一份（内容相同），任选其一：

- GitHub：https://github.com/weiwei-run/jobbot-agent
- Gitee：https://gitee.com/acweiwei/jobbot-agent

**方式 A：用 git 下载（推荐，以后更新方便）**

打开命令提示符（Windows 按 `Win+R` 输入 `cmd` 回车），执行：

```bat
git clone https://github.com/weiwei-run/jobbot-agent.git
```

或者从 Gitee 拉：

```bat
git clone https://gitee.com/acweiwei/jobbot-agent.git
```

**方式 B：网页下载 ZIP**

- GitHub：打开项目页 → 绿色 `Code` 按钮 → `Download ZIP`
- Gitee：打开项目页 → 右侧「下载 ZIP」

下载后解压到一个好找的文件夹，比如 `D:\jobbot-agent`。

## 四、启动 JobBot

1. 打开命令提示符（`Win+R` → `cmd`）；
2. 进入项目目录：

```bat
cd /d D:\jobbot-agent
```

3. 启动：

```bat
python start.py
```

看到 `✅ JobBot 已启动！👉 http://localhost:9379` 后，浏览器会自动打开看板页面。以后每次用都这样启动。

> macOS / Linux 用终端，命令一样（`cd` 不需要 `/d`）。

## 五、第一次使用，按顺序做四步

### 第 1 步：配置 AI（填 API Key）

页面顶部「第一步：配置 AI」有三个输入框：

- **API 地址 (Base URL)**：填你用的服务商地址
- **模型**：填模型名
- **API Key**：填你的密钥

填完点「测试连接」，显示成功就可以继续。

常用服务商参考（模型名以各厂商官网文档为准）：

| 服务商 | API 地址 | 模型示例 |
|--------|----------|----------|
| DeepSeek（推荐） | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 阿里通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| Kimi（月之暗面） | `https://api.moonshot.cn/v1` | `kimi-k2` 等 |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` 等 |

> API Key 只保存在你电脑的 `config/llm.json` 里，不会上传到任何地方。

### 第 2 步：上传简历 + 填写意向

页面「第二步：简历与求职意向」：

- **上传简历**：支持 TXT / Word / PDF。点上传区域选文件，JobBot 会自动解析出姓名、学历、专业、技能、证书等，填进下面的意向框（可手动修改）。
- **意向描述**：确认解析结果，补上你没写在简历里的信息。写清楚最好：
  - 学历：`大专`
  - 毕业届别：`2027毕业`
  - 目标岗位：`电气自动化、机器人`
  - 技能：`PLC编程调试、ABB工业机器人`
  - 薪资期望：`3000-6000`
- **目标城市**：默认南京，改成你求职的城市。

改完点「保存意向」。（输入时会自动保存，这个按钮可以不点。）

### 第 3 步：检测环境 + 平台登录（BOSS直聘/实习僧）

「平台与浏览器环境」区域：

- 51job：**无需登录**，开箱即用。
- BOSS直聘 / 实习僧：需要 Camofox 浏览器 + 登录一次。
  - 没装 Camofox 时，看板会提示，先安装：

    ```bat
    npm install -g @askjo/camofox-browser
    ```

  - 点「检测环境」，确认 Camofox 已运行、平台状态为「已登录」。
  - 未登录的话点「打开登录页」，浏览器会弹出登录页，你**手动**登录（扫码/验证码都行），登录完回到页面点「已登录，继续」。

> JobBot 不会自动登录、不会替你填验证码。这是刻意的安全设计，所有登录都由你自己完成。

### 第 4 步：开始搜索

点「⚡ 开始搜索」，页面会弹出一个进度遮罩，依次显示：

`检查登录状态 → 生成搜索关键词 → 提取求职画像 → 硬指标过滤 → AI 粗筛 → 校验岗位有效性 → AI 精排`

这一步通常要几分钟（要逐条打开岗位详情核实），遮罩期间不要操作页面，等它结束自动收起。

## 六、搜索结果怎么看

每条推荐岗位会显示：

- **总分（0~100）+ 档位**：
  - 85 分以上 = 高度匹配
  - 70~84 = 推荐投递
  - 50~69 = 备选
  - 50 分以下不展示
- **分项分**：硬技能 / 项目实习 / 学历专业 / 证书 / 城市方向，各维度得分
- **命中证据**：✅ 你简历里哪些内容命中了岗位要求（如"机器人视觉标定（部分）：ABB工业机器人实操"）
- **缺口**：❌ 岗位要求但你没体现的（如"JD 必备技能「CAD电气图纸」画像中无证据"）
- **一句话理由**：如"硬技能命中 2 项，经历相关，总分 82（推荐投递）"

操作区：

- **🔗 打开详情投递**：新标签页打开岗位详情，你自己在网页上投递
- **📝 加入记录**：投递后点它，把岗位记进本地看板（默认状态=已投递）
- **平台筛选**：全部平台 / BOSS直聘 / 51job / 实习僧，只看某个平台的推荐
- **下一页 / 上一页**：每页 10 条，翻页看更多

如果当次没有合适的岗位，页面会如实提示，并给出黄色「更换关键词示例」供你下次换词搜索。

## 七、投递记录怎么看、怎么跟进

- **投递总览**：四张统计卡（总记录 / HR 回复 / 约面试 / 已拒绝），一眼看进度。
- **投递记录**：完整表格，点行可展开详情（JD、薪资、评分分项、证据、缺口）；可以按平台/状态筛选、排序。
- **状态跟进**：每条记录旁有按钮，投递后按实际情况点：
  `已投递 → 已回复 → 约面试 → Offer`（不合适就点「拒绝」）。
- **CSV 导出**：点右上角按钮，把记录导出成表格文件。

## 八、常见问题

**Q：启动时提示端口被占用？**
JobBot 可能已经在运行，直接打开浏览器访问 `http://localhost:9379` 即可；或者关掉旧的 cmd 窗口再启动。

**Q：某个平台显示"未登录，本次跳过"？**
按第 5 步第 3 节登录该平台，再重新搜索。

**Q：实习僧提示"未解析到岗位（可能被风控拦截或页面结构变化）"？**
这是平台方风控或改版导致的，不是电脑问题。等一会儿再搜，或换关键词试试。

**Q：某条岗位显示"评分失败，按备选档位展示"？**
AI 偶尔调用异常，JobBot 会如实标注并按备选展示，不影响其他岗位；重新搜索通常会恢复。

**Q：搜出来的岗位太少/没有合适的？**
完善意向描述（补上技能、证书、薪资期望），或按黄色提示换关键词，多搜几轮。

**Q：被平台风控（验证码/IP 限制）？**
放慢搜索频率，或者换个网络。遇到验证码请人工处理，JobBot 不会绕过。

## 九、数据与备份

所有数据都在项目文件夹里：

- `config/llm.json`：你的 API Key 配置
- `config/user_profile.json`：简历解析结果与意向
- `data/applications.json`：投递记录

想备份或换电脑：把整个项目文件夹复制过去，或者至少备份 `config/` 和 `data/` 两个目录。

## 十、安全提醒

- 不要把你的 API Key 发给任何人（包括所谓的"客服"）。
- JobBot 绝不自动登录、不填验证码、不绕过任何登录墙。
- 卸载 = 删除项目文件夹，没有后台残留。
