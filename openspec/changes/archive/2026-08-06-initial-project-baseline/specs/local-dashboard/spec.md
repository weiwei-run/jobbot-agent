## Purpose

提供本地单文件 Web 看板与 HTTP API（端口 9379），承载 LLM 配置、简历与意向、搜索评分、自动投递、记录管理、在线同步设置等完整操作界面，并支持后台任务进度、登录引导与 CSV 导出。

## ADDED Requirements

### Requirement: 本地服务启动

系统 SHALL 支持通过 `python start.py` 一键启动（环境检查、启动看板、打开浏览器），也支持直接运行看板脚本；看板监听 127.0.0.1:9379；端口被占用时 SHALL 给出明确提示。

#### Scenario: 正常启动
- **WHEN** 用户运行 `python start.py`
- **THEN** 系统完成环境检查、启动看板并打开浏览器访问 9379 端口

#### Scenario: 端口被占用
- **WHEN** 看板端口已被其他进程占用
- **THEN** 系统提示端口占用且 JobBot 可能已在运行

### Requirement: 配置界面

系统 SHALL 在看板中提供 LLM 配置、求职意向、在线同步设置的编辑与保存界面；已保存的 API Key SHALL 不回显明文。

#### Scenario: 保存 LLM 配置
- **WHEN** 用户在设置页填写 LLM 配置并保存
- **THEN** 配置持久化，界面仅显示已保存占位符而非明文 Key

### Requirement: 搜索与投递操作

系统 SHALL 在看板中提供"开始搜索"按钮（异步执行并实时展示进度、关键词、警告与候选岗位）、对候选岗位的投递按钮，以及平台登录引导按钮。

#### Scenario: 发起后台搜索
- **WHEN** 用户点击开始搜索
- **THEN** 系统异步执行搜索，界面展示当前步骤与进度，完成后展示结果

### Requirement: 记录看板与统计

系统 SHALL 在看板中展示投递统计卡片（总投递、各状态数量）、投递记录表格，支持按平台与状态筛选、按字段排序、展开详情、更新状态，并支持 CSV 导出。

#### Scenario: 导出 CSV
- **WHEN** 用户点击 CSV 导出按钮
- **THEN** 系统下载包含当前投递记录的 CSV 文件

### Requirement: 登录引导与轮询

系统 SHALL 在平台未登录时展示登录提示区（打开登录页、已登录继续按钮），并在登录状态变化时更新界面；后台定期刷新数据保持看板同步。

#### Scenario: 平台需要登录
- **WHEN** 搜索或投递返回需要登录的平台
- **THEN** 看板显示登录引导，用户确认已登录后可继续原操作
