# 信任检测 — 诈骗/幽灵岗位识别

## 检测维度

### 1. 关键词检测

发现以下词 → **扣信任分**：
- "在家办公"、"日结"、"押金"、"培训费"、"先交"
- "刷单"、"兼职"、"微商"、"代理"、"投资"、"理财"
- "虚拟币"、"区块链"

发现以下词 → **标记高风险**：
- "日入"、"月入过万"、"躺赚"、"带你赚钱"

### 2. 薪资虚高检测

月薪上限超过平台配置的 `salary_ceiling`（默认 15000），且：
- 学历要求大专及以下
- 经验要求"不限"或"应届生"

→ 标记为可疑（可能是挂羊头卖狗肉）

### 3. 公司信号

以下信号需注意：
- 公司行业为"专业服务(咨询、人力资源)" → 可能是外包/猎头
- 公司名包含"科技""网络"但岗位是普工 → 不匹配
- 公司规模 < 20人但批量发布多个不同行业岗位 → 可能是培训机构
- JD中出现"实习地点不在XX""需要去外地培训" → 劳务派遣

### 4. 已确认的培训/外包公司模式

以下模式需警惕：
- **河南涛沫网络科技等**：计算机服务公司，批量发布工业机器人/AI/电气工程师岗位 → 疑似培训
- **智光集能等**：多个分公司发布相同JD，实际是云南某运维公司的劳务派遣
- **河北中聘/金澜等**：人力资源公司，非直接雇主
- JD含"实习地点非南京""需异地实习3-6个月""入职公司非发布公司"

## 处理策略

- 标记但不自动过滤（用户可能就是想投这类公司）
- 在评分时附加信任评级（如"⚠️ 信任分偏低：公司为人力资源公司"）
- 给用户展示时标注风险
